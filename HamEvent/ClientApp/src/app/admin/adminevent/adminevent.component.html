{{ 'Recommended setup presets (common logging software)' | translate }}

N1MM Logger+
  1. Configure ADIF export for each operator station (or periodic export).
  2. Use a post-export script to call the upload endpoint.
  3. Send exported .adi as multipart field file.
Log4OM
  1. Enable ADIF auto-export profile.
  2. Trigger external command after export (or via scheduled task).
  3. Upload generated ADIF to this event endpoint.
DXKeeper / DXLab
  1. Create ADIF export definition for event QSOs.
  2. Use launcher automation to run upload command after export.
  3. Keep event secret in a local env var, not in plain profile notes.
Win-Test
  1. Export ADIF at intervals or at operator handover.
  2. Run a helper script to POST ADIF file to API.
  3. Retry upload on temporary network errors.
N3FJP / ACLog
  1. Export ADIF from contest log module.
  2. Attach a script or scheduled uploader for near-live sync.
  3. Use one endpoint per event to avoid cross-event uploads.
Ham Radio Deluxe
  1. Export selected QSOs to ADIF.
  2. Call upload API from PowerShell/batch helper.
  3. Validate successful response before deleting local export file.

Generic uploader scripts (works with any logger)

PowerShell:

$url = {{ powerShellUploadUrl }}
Invoke-RestMethod -Method Post -Uri $url -Form @{ file = Get-Item 'C:\logs\event.adi' }

Linux/macOS shell:

curl -X POST {{ shellUploadUrl }} -F "file=@/var/log/event.adi"

Tip: if your logger has direct ClubLog upload only, keep that for ClubLog and add this script as an additional export target for HamEvent.
